# 局域网文件分享

基于 Electron + Vue3 + Express 的局域网 HTTP 文件分享工具。

## 项目结构

```
lan-share/
├── package.json              # 项目配置与依赖
├── index.html                # 入口 HTML
├── vite.config.js            # Vite 构建配置
├── .gitignore
├── scripts/
│   └── dev.js                # 开发模式启动脚本
├── share/                    # 共享文件存放目录
│   └── .gitkeep
└── src/
    ├── main.js               # Electron 主进程
    ├── preload.js            # 预加载脚本（IPC 桥接）
    ├── server.js             # Express HTTP 文件服务
    └── renderer/
        ├── main.js           # Vue3 入口
        └── App.vue           # 主界面组件（含样式）
```

## 功能列表

### 窗口界面

| 功能 | 说明 |
|------|------|
| 服务状态指示 | 绿色脉冲动画 = 运行中，红色 = 已停止 |
| 端口设置 | 输入框，默认 18080，运行中时锁定 |
| 启动/停止服务 | 一键切换 HTTP 服务开关 |
| 本机地址显示 | 自动获取局域网 IPv4（192.168.x.x） |
| 复制地址 | 一键复制访问 URL 到剪贴板 |
| 在浏览器打开 | 调用系统默认浏览器打开访问地址 |
| 打开共享目录 | 调用资源管理器打开 share 文件夹 |

### 远程访问

| 功能 | 说明 |
|------|------|
| 访问地址展示 | 显示完整 HTTP 地址供其他设备访问 |
| 二维码 | 实时生成，手机扫码即可访问 |

### 文件管理

| 功能 | 说明 |
|------|------|
| 添加文件 | 弹出文件选择对话框，支持多选 |
| 添加文件夹 | 弹出目录选择对话框，整个文件夹复制到 share |
| 刷新 | 重新读取 share 目录，更新文件列表 |
| 清空全部文件 | 一键删除 share 目录下所有内容 |
| 拖拽上传 | 拖拽文件/文件夹到虚线区域上传 |
| 文件列表 | 显示名称、大小、修改时间 |
| 文件图标 | 按扩展名自动匹配彩色图标 |
| 下载文件 | 弹出保存对话框，选择保存位置 |
| 删除文件 | 确认后删除单个文件 |

### HTTP 浏览器端（其他设备访问）

| 功能 | 说明 |
|------|------|
| 文件列表 | 表格展示所有共享文件 |
| 拖拽上传 | 浏览器内拖拽文件上传 |
| 下载文件 | 点击按钮直接下载 |
| 删除文件 | 确认后删除 |

### 安全

| 功能 | 说明 |
|------|------|
| 路径穿越防护 | `../` 路径逃逸检测，禁止访问 share 目录外的文件 |
| 上传限制 | 单文件最大 10GB |
| Express 监听 | 绑定 `0.0.0.0`，允许局域网访问 |

## 运行命令

```bash
# 安装依赖
npm install

# 开发模式（热更新）
node scripts/dev.js

# 构建前端
npx vite build

# 打包 exe
npx electron-builder --win

# 一键构建+打包
npm run build
```

## 技术栈

- Electron 28
- Vue 3（Composition API + setup 语法糖）
- Vite 5
- Express 4
- multer（文件上传）
- qrcode（二维码生成）
- mime-types（MIME 类型检测）
